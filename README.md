# Employee Management with Face Recognition

A Tkinter-based GUI app to manage employee data with integrated face recognition.

## Features
- Add, update, delete, and search employee records.
- Upload and store profile images.
- Face recognition module integration.

## Requirements
- Python 3.x
- Tkinter (standard with Python)
- OpenCV (likely needed for `facerecognition.py`)

## How to Run
```bash
python main.py
